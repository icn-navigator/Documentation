**Welcome!**

This document is intended for **clients, stakeholders, and future users** of the ICN Navigator prototype.  It provides an overview of the platform’s purpose, how to access it, and what to expect when using it.  
## Overview

**ICN Navigator** is a prototype platform for browsing organisations and their capabilities across Victoria. It provides a map-based interface and filtering tools to explore organisations by sector, region, capabilities and more. 

This application was developed as part of **COMP30022 – IT Project** by **Team ZAMJO** (see [[Roles and Responsibilities]]) for our client, **ICN Victoria**.

For a discussion of features see [[Features by Sprint]].

## Accessing the Application

### Web App

The web application is currently hosted at [https://icn-navigator.onrender.com/](https://icn-navigator.onrender.com/).  

Please note that the site may take a short while to load initially, as Render servers can enter a temporary sleep state when inactive and require time to spin up. If the hosting plan is upgraded or the deployment provider changes (see [[For Developers#Deployment]] for more details), this delay will no longer occur.

### Mobile App

The mobile app is not currently deployed, as full deployment would require an Apple Developer account and associated subscription fees, along with TestFlight setup and related configuration steps.  For this project, we chose not to pursue full deployment due to these costs. 

Details on how mobile deployment could be configured in the future are provided in [[For Developers#Deployment]].

The app can still be run locally for testing and demonstration purposes using a developer build.  For instructions on setting this up, see the `README` in the main repository:  [https://github.com/icn-navigator/ICN-Navigator](https://github.com/icn-navigator/ICN-Navigator)
