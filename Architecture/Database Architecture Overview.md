
## DB Schema Diagram

This is the core DB schema for the app, based on the relevant requirements for sprint 1

![[ICN Navigator DB Schema.pdf]]

The current planned database schema accounts for the relevant requirements for the current functionality of the app.

>[!Info] Note:
>The data structure of the ICN directories themselves are *not included* in this schema, as in the production application we will not be hosting ICN data in our own relational database - and it is assumed to be accessible by our app through a remote database connection.
>
>When we approach the data processing stages of planning and implementation, this document will be updated to represent the ICN schema we're using for *development only*, with the provided test data.
