# Welcome  

This is the online version of the documentation for the **ICN Navigator Project**, created for the subject **COMP30022 – IT Project**.  

Written by team **ZAMJO** (see: [[Roles and Responsibilities]])

This documentation serves as a **centralised hub** for collating all key information related to the project, including:  

* Team management
* Agile ceremonies and workflows  
* Planning
* Research and discovery work  
* Decision records and justifications  
* Information sharing
* Technical documentation and deliverables  

## Navigation  

The documentation is organised in a **file-like structure**, with interlinked pages to make it easy to move between related content.  
* Most pages are **cross-referenced** where relevant, so following links will help you follow decisions, requirements, and design artefacts.  
* Some pages include **embedded images, diagrams, and PDFs** to provide additional context (these are downloadable if you wish to view them in fullscreen)

Alternatively, you can also work with the raw documentation directly:  
* Clone the repository: [icn-navigator/Documentation](https://github.com/icn-navigator/Documentation)  
* Open in any markdown-supported environment (we recommend [Obsidian](https://obsidian.md/))
