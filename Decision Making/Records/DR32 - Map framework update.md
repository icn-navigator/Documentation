## Background
We were debating whether or not Mapbox was suitable for mobile, since you would need separately code android and ios, which is a bit redundant. We wanted to explore our options.

## Relevant Data
Through research, Mapbox requires separate code blocks for android and ios. React native maps on the other hand, automatically handles both, so coding is seamless.

## Options considered
**Option 1: React native maps**
- this is seamless within react native and caters to our needs perfectly

**Option 2: explore other pathways**
- we knew beforehand that react native maps would be the best choice

## Action items
- start coding with react native maps
- update architecture

## Outcome
The team decided to use React native maps for our map api.
