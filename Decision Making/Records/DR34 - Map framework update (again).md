## Background
We need to update our map framework. As the app gets more complex and requires more features, react native maps is not able to keep up. For example, react native maps doesnt support a web feature, which is one of the more important features the client asked for. A library that used to solve this problem was react-native-web-maps, but this is no longer being supported.

## Relevant Data
- React native maps is not available of web
- react native web maps is no longer being supported

## Options considered
**Option 1: Mapbox**
- this is what we had previously considered to be our final map framework. Before we switched to native maps.

## Action items
- start coding the switch to mapbox

## Outcome
The team decided to use mapbox
