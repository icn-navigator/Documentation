## Background
Sprint feedback highlighted that while meeting notes were good, they lacked clear **assignee information** for action items. Additionally, decisions recorded in notes were not consistently linked to GitHub issues or the Decision Log.

## Relevant Data
- Action items were sometimes ambiguous without a named owner.  
- GitHub integration allows linking directly to issues/user stories.  
- Decision Log traceability is important for client transparency.  

## Options Considered
**Option 1: Keep current meeting notes style**  
- Pro: Fast and informal.  
- Con: Missing accountability; harder to track actions.  

**Option 2: Add assignees only**  
- Pro: Improves accountability.  
- Con: Still lacks traceability to issues/decisions.  

**Option 3: Add assignees + link to GitHub issues and Decision Log (Chosen)**  
- Pro: Clear ownership and traceability.  
- Con: Slightly more work during note-taking.  

## Action Items
- Update meeting notes template to include assignee for each action item.  
- Link relevant GitHub issues/user stories in action items.  
- Link decisions to their corresponding DR entries in the Decision Log.  

## Outcome
The team decided to **improve meeting notes by adding assignees and links** to GitHub issues and the Decision Log.  
This ensures accountability and traceability of decisions and actions.
